本地模型，一次安装自动识别

  1. 获取安装包

    在官网网盘获取“熙梦引擎一键安装-1.0.0”完整文件夹，保留 EXE、安装组件、语音压缩包、修复包和 model.zip；不要只下载小 EXE。

  2. 一键安装

    先关闭助手，再运行“熙梦引擎一键安装.exe”，选择含 DyCast.exe 的安装目录。安装器自动解压 engine、修复 Python、部署 Ollama 并导入 Qwen2.5 7B；程序和模型放在所选目录，不强制写入 C 盘。

  3. 在助手中启用

    等待安装成功后打开助手 → 语音回复 → LLM 接口。专用端口通常为 11435，若被占用会在 11435–11445 中选择；以软件自动填写为准，Key 留空。已有云端配置时点击“使用本地模型”切换，再测试回复。

  4. 或者走云端 API

    不想装本地模型？在 LLM 接口里填任意 OpenAI 兼容地址、API Key 和模型名，回复更聪明，按用量付费。

语音引擎 · 决定“怎么说”

四条语音路线，不必都安装

  1. 选一条路线

    希望先快速开播，可在“语音与音色”选择内置 Edge TTS：联网即可使用，无需 Python、本地模型或客户 API Key。需要本地克隆音色再选择 GPT-SoVITS 或 IndexTTS-2。

  2. 下载并放置

    运行配套的一键安装器，把语音引擎部署到所选助手目录的 engine。手工部署时应与 DyCast.exe 同级；软件也兼容升级迁移到上一级的 engine。GPT-SoVITS 与 IndexTTS-2 共用 9880 端口，同时只运行一种。

  3. 克隆你的音色

    上传一段清晰、无伴奏的人声，可上传多段融合音色；不上传则使用内置音色。听不清参考音频时开启“无参考文本模式”。

  4. 云端路线

    已有 OpenAI 兼容语音服务？直接填 API 地址即可，本地引擎可以完全不装。

BEFORE YOU START · 运行准备

下载前，确认这些条件

WIN

系统要求

Windows 10 22H2 或 Windows 11 64 位，建议 SSD。完整本地引擎安装时，目标盘建议预留 40 GiB；安装文件夹本身也需存储空间。只用 Edge 或云端接口不需要整套本地引擎。

MIN

本地模型最低配置

Qwen2.5 7B 建议现代 4 核处理器、至少 16GB 内存。CPU 可参与推理，但首次加载和回复速度受硬件影响；安装成功、识别模型不等于已经达到实时直播速度。

REC

直播推荐配置

6 核 12 线程处理器、32GB 内存、6GB 以上显存；同时运行本地模型与语音引擎时，建议 8GB 以上显存。

!
先装客户端；本地大模型与语音引擎可一次部署

正式版 2.1.26 保留月卡机制。配套引擎安装器 1.0.0 统一部署语音引擎、Ollama 和 Qwen，使用时完整保留安装文件夹。大文件落在所选目录；少量 Windows 或客户端配置仍可能保存在用户目录。旧显卡请核对驱动并实际测试推理，Edge TTS 需要联网。

和抖音自带的语音助手有什么区别？＋

自带的语音助手只能把弹幕读出来。熙梦直播助手的核心是“替你回复”：接入大语言模型理解弹幕并生成回答，配合你的音色播报，还能自动感谢礼物、欢迎进场、冷场救场，并把弹幕转发给互动游戏。大模型和语音都能走本地，装一次长期低成本使用。

本地大模型需要什么电脑配置？＋

配套离线包为 Qwen2.5 7B，建议至少 16GB 内存、现代 4 核 CPU；直播与本地语音同时运行推荐 32GB 内存。整套本地引擎目标盘建议预留 40 GiB，另需安装文件夹空间。CPU 实际推理已验证；旧显卡驱动可能导致预热很慢，显卡性能需按机器实测，不能只凭“已识别”判断速度。

连接直播间后一直没有弹幕怎么办？＋

先核对所选平台、房间号和开播状态。抖音凭证过期时重新扫码；B站需在左下角确认登录，重新连接后可导出 B站诊断。平台消息类型和可用信息可能不同，以实际收流为准。

本地语音引擎提示“未找到”怎么办？＋

先确认选择的是 GPT-SoVITS 或 IndexTTS-2；内置 Edge 不需要本地引擎。可关闭助手，运行引擎一键安装器并选择含 DyCast.exe 的目录。程序也兼容升级后放在上一级的 engine；不要只移动其中的 Python 或模型文件。

试听没有声音，或者一直显示启动中？＋

到“队列与连接”查看服务状态。确认 9880 端口没有被其他程序占用，必要时点击“释放 9880 并重启引擎”。首次加载模型耗时会更长。

LLM 测试失败应该检查什么？＋

新版配套引擎一般使用 http://127.0.0.1:11435/v1，端口可在 11435–11445 自动选择；原有系统 Ollama 的 11434 也兼容，以软件自动识别为准。Key 留空、模型为 qwen2.5:7b。已有云端配置时点击“使用本地模型”；首次加载较慢可适当调高请求超时，并查看 engine/ollama/logs/server.log。

如何购买和使用激活码？＋

访问官方激活码购买页完成购买，启动软件后将激活码填入激活界面即可。月卡从首次激活起 30 天，一台机器绑定一个 Key，允许断网使用最长 24 小时；换机需联系管理员解绑。本机推理不按条数额外收费。

怎样退出或更换 B站登录账号？＋

当前版本没有独立退出按钮。先完全关闭助手，按 Win + R 输入 %APPDATA%\DyCast\Partitions，只删除其中的 ximeng-bilibili 文件夹，再启动助手重新扫码。不会退出外部浏览器账号，也不会清除月卡、抖音会话和其他软件设置。

关闭助手后，模型服务还会运行吗？＋

2.1.26 会停止由本软件启动的 Ollama 和模型子进程；你自行启动或其他软件使用的 Ollama 不会被一并结束。安装器只在完成检查时临时启动专用服务。

只发一个引擎安装 EXE 可以吗？＋

不可以。它是离线安装入口，旁边还需保留“安装组件”、语音引擎压缩包、Python 修复包和 ollama_大语言模型/model.zip。完整下载整个安装文件夹后再运行。

软件如何检查和安装新版本？＋

从 v2.1.9 开始，软件启动并完成授权后会自动检查更新；也可在月卡状态区域点击“检查更新”。发现新版后点击“立即下载更新”，下载并运行新版安装包即可，原有配置和本地引擎会继续保留。

SessionID 会上传到其他服务器吗？＋

SessionID 保存在本机，用于建立直播间连接。请不要向他人发送或公开展示凭证；失效后重新扫码获取即可。
