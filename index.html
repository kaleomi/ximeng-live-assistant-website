语音与音色

选择适合你的发声方式

  1. 选择播报引擎

    GPT-SoVITS 和 IndexTTS-2 适合本地声音克隆；OpenAI 兼容 API 适合云端服务。

  2. 准备本地引擎

    使用本地引擎时，将完整的 engine 文件夹放在“熙梦直播助手.exe”旁边，再重启程序。

  3. 上传参考音色

    选择清晰、无背景音乐的人声片段。可上传多段音频融合音色，不上传则使用预设音色。

  4. 试听与调整

    调整音量、语速和采样参数，输入测试文本并试听，满意后再开启语音助手。

LLM 接口

让回复更贴合直播风格

  1. 填写 API 信息

    支持 OpenAI 兼容协议。填写 Base URL、API Key 和模型名称；本地免鉴权服务可不填 Key。

  2. 测试连接

    输入一条模拟弹幕，点击“测试连接与回复”，先确认接口能够正常返回文字。

  3. 编辑两类提示词

    “弹幕回复”控制观众问答，“冷场闲聊”控制无人发言时的主动话术，两者互不覆盖。

  4. 设置触发规则

    按需要调整回复间隔、过滤词和本地关键词规则，避免短时间内重复播报。

连接直播间后一直没有弹幕怎么办？＋

先确认直播间正在开播，并检查左下角连接状态。若提示凭证失效，重新扫码获取 SessionID；若网络拥堵，断开后等待几秒再连接。

本地语音引擎提示“未找到”怎么办？＋

检查程序目录下是否存在完整的 engine 文件夹，并确保它与“熙梦直播助手.exe”处于同一级目录。补齐后完全退出软件再重新打开。

试听没有声音，或者一直显示启动中？＋

到“队列与连接”查看服务状态。确认 9880 端口没有被其他程序占用，必要时点击“释放 9880 并重启引擎”。首次加载模型耗时会更长。

LLM 测试失败应该检查什么？＋

核对 API 地址、Key 和模型 ID。地址可填写 Base URL，也可填写以 /chat/completions 结尾的完整地址。本地免鉴权服务可以留空 Key。

SessionID 会上传到其他服务器吗？＋

SessionID 保存在本机，用于建立直播间连接。请不要向他人发送或公开展示凭证；失效后重新扫码获取即可。
