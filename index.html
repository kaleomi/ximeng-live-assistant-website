先给助手一个“大脑”

  1. 获取安装包

    打开官网同款网盘分享，进入“大语言模型 / Ollama”文件夹，下载完整安装包（含 OllamaSetup.exe 与 qwen2.5:7b 模型包）。

    不想装本地模型？在 LLM 接口里填任意 OpenAI 兼容地址、API Key 和模型名，回复更聪明，按用量付费。

助手本体 · 直播工作台

装好本体，连接直播间

  1. 下载并解压

    在网盘分享中下载“熙梦直播助手”最新安装包（文件名含 2.1.6），双击安装并按向导完成后，从桌面快捷方式启动。升级安装会保留现有配置和本地引擎。

  2. 扫码登录

    点击“扫码登录”，用抖音 App 扫码自动获取 SessionID；凭证只保存在本机，失效后重新扫码即可。

  3. 连接直播间

    粘贴房间号、直播间链接或分享链接，点击“连接”。左侧状态变绿、弹幕开始滚动即成功。

  4. 配置语音回复

    进入“语音回复”，编辑智能回复提示词、六类互动话术和触发频率，打开总开关即可开播。

语音引擎 · 决定“怎么说”

三选一，按电脑配置选声音

  1. 选一条路线

    普通电脑推荐 GPT-SoVITS：响应快、中文自然；高配电脑选 IndexTTS-2：音质更好、情感更足。两者都在本机运行，不按条数收费。

  2. 下载并放置

    在网盘分享中下载对应引擎压缩包，解压后将完整的 engine 文件夹放在“熙梦直播助手.exe”旁边，重启程序。

  3. 克隆你的音色

    上传一段清晰、无伴奏的人声，可上传多段融合音色；不上传则使用内置音色。听不清参考音频时开启“无参考文本模式”。

  4. 云端路线

    已有 OpenAI 兼容语音服务？直接填 API 地址即可，本地引擎可以完全不装。

和抖音自带的语音助手有什么区别？＋

自带的语音助手只能把弹幕读出来。熙梦直播助手的核心是“替你回复”：接入大语言模型理解弹幕并生成回答，配合你的音色播报，还能自动感谢礼物、欢迎进场、冷场救场，并把弹幕转发给互动游戏。大模型和语音都能走本地，装一次长期低成本使用。

一定要装本地大模型吗？＋

不用。本地 Ollama 零成本、断网可用，建议 16GB 内存和 12GB 磁盘空间；电脑配置低或想更省事，可以直接在 LLM 接口里填 OpenAI 兼容 API 地址，回复更聪明，按用量付费。

连接直播间后一直没有弹幕怎么办？＋

先确认直播间正在开播，并检查左下角连接状态。若提示凭证失效，重新扫码获取 SessionID；若网络拥堵，断开后等待几秒再连接。

本地语音引擎提示“未找到”怎么办？＋

检查程序目录下是否存在完整的 engine 文件夹，并确保它与“熙梦直播助手.exe”处于同一级目录。补齐后完全退出软件再重新打开。

试听没有声音，或者一直显示启动中？＋

到“队列与连接”查看服务状态。确认 9880 端口没有被其他程序占用，必要时点击“释放 9880 并重启引擎”。首次加载模型耗时会更长。

LLM 测试失败应该检查什么？＋

本地安装包装好后，地址会自动识别为 http://127.0.0.1:11434/v1，Key 留空、模型 qwen2.5:7b。使用云端 API 时，核对地址、Key 和模型 ID；地址可填 Base URL，也可填以 /chat/completions 结尾的完整地址。

如何购买和使用激活码？＋

访问官方激活码购买页完成购买，启动软件后将激活码填入激活界面即可。激活为月卡制，本机推理不按条数额外收费。

SessionID 会上传到其他服务器吗？＋

SessionID 保存在本机，用于建立直播间连接。请不要向他人发送或公开展示凭证；失效后重新扫码获取即可。
